# Волонтёр на связи (Volunteer Connect)

Учебный проект по дисциплине **«Разработка мобильных приложений»**.  
Кроссплатформенное приложение (`.NET MAUI Blazor Hybrid` + `Telerik UI for Blazor`), предназначенное для координации адресной помощи пожилым людям со стороны волонтёров.

---

## О проекте

Приложение связывает пожилых людей (подопечных), которым требуется бытовая или социальная поддержка, с проверенными волонтёрами. Пользователи могут создавать заявки на покупку продуктов и лекарств, сопровождение в медицинские учреждения, помощь по дому или общение.

### Цели учебного проекта
* Проектирование клиент-серверной архитектуры мобильного приложения.
* Реализация ролевой модели доступа (**RBAC**) и защищённой аутентификации.
* Работа с облачными базами данных и синхронизацией состояния в реальном времени.
* Интеграция картографических сервисов и системы push-уведомлений.
* Разработка адаптивного пользовательского интерфейса на базе компонентов **Telerik UI for Blazor**.

---

## Функциональные модули (9 модулей)

1. **Регистрация и безопасная аутентификация**  
   Вход в систему по учётным данным с использованием шифрованного канала связи (TLS), токенов доступа (JWT) и разграничением прав на уровне интерфейса и API.
2. **Профили пользователей и ролевая модель (RBAC)**  
   Поддержка ролей *«Пожилой человек (Подопечный)»*, *«Волонтёр»* и *«Координатор»*. Отображение контактных данных, района проживания, навыков волонтёра и статистики выполненных задач.
3. **Создание запросов о помощи**  
   Интуитивно понятная форма для пожилых людей с выбором категории помощи (*продукты, лекарства, сопровождение в поликлинику, домашние дела, общение*), указанием адреса и подробного описания.
4. **Назначение задач в реальном времени**  
   Мгновенный отклик волонтёров на открытые заявки с автоматической привязкой исполнителя и блокировкой повторного взятия задачи.
5. **Интерактивная карта (`TelerikMap`)**  
   Отображение геолокации активных заявок на карте города (OpenStreetMap) с информационными подсказками по каждой точке.
6. **Push-уведомления (`TelerikNotification` / FCM)**  
   Мгновенное оповещение участников о ключевых событиях: создании новой заявки, назначении волонтёра, изменении статуса и получении отзыва.
7. **Сообщения внутри приложения (Чат)**  
   Встроенный мессенджер, привязанный к конкретной заявке, для уточнения списка покупок, времени визита и деталей маршрута.
8. **Отслеживание статуса запроса**  
   Прозрачный жизненный цикл каждой заявки с цветовой индикацией (`TelerikBadge`): *«Открыт»* → *«В работе»* → *«Выполнен»*.
9. **Система обратной связи и оценки волонтёров (`TelerikRating`)**  
   После завершения задачи подопечный выставляет оценку по 5-балльной шкале и оставляет текстовый отзыв, на основе чего автоматически пересчитывается рейтинг волонтёра.

## Технологический стек

* **Фреймворк:** .NET 8 / .NET MAUI Blazor Hybrid (C#, Razor)
* **UI-библиотека:** Progress Telerik UI for Blazor (`TelerikGrid`, `TelerikMap`, `TelerikTabStrip`, `TelerikNotification`, `TelerikRating`, `TelerikDialog`, `TelerikCard`)
* **Картография:** OpenStreetMap Tile Layer
* **Облачные сервисы и бэкенд (архитектурный слой):**
  * Аутентификация: JWT / OAuth 2.0 + `SecureStorage`
  * Синхронизация в реальном времени: ASP.NET Core SignalR / Cloud Firestore
  * Уведомления: Firebase Cloud Messaging (FCM)

## Запуск проекта

### Вариант 1: Быстрый запуск в Telerik REPL for Blazor (без установки IDE)
1. Перейдите в [Telerik REPL for Blazor](https://telerik.com). [https://blazorrepl.telerik.com/QAFvbDcE38fX51gj50]
2. Скопируйте код из файла `__Main.razor` данного репозитория и вставьте его в редактор REPL.
3. Нажмите **Run** (`Ctrl + S`).

### Вариант 2: Локальный запуск в Visual Studio 2022
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com<ваш-логин>/volunteer-connect-blazor.git
   ```
2. Убедитесь, что установлены рабочие нагрузки **.NET Multi-platform App UI development** и пакет NuGet `Telerik.UI.for.Blazor`.
3. Откройте решение `VolunteerConnect.sln`, выберите целевую платформу (`Windows Machine` или эмулятор `Android`) и нажмите **F5**.
