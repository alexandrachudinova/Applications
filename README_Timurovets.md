# ИС «Тимуровец» — Доступная информационная система поддержки и заботы

Учебный проект по дисциплине **«Разработка программных модулей для компьютерных систем»**.  
**«Тимуровец»** — это доступное настольное/веб-приложение на базе **Blazor** и **Telerik UI**, созданное для помощи пожилым людям и пользователям с особыми потребностями в контроле здоровья, планировании медицинских событий и экстренной связи с близкими.

---

## Основные возможности системы

1. **Контроль приёма лекарств:**
   - Просмотр расписания приёма препаратов на текущий день с указанием времени и дозировки.
   - Отметка о выполнении приёма в одно нажатие крупной кнопкой.
   - Добавление новых напоминаний через упрощённое диалоговое окно.
2. **Управление медицинскими приёмами:**
   - Карточки предстоящих визитов ко врачу с указанием специализации, даты, времени и адреса клиники.
   - Отправка уведомлений-напоминаний членам семьи и опекунам.
3. **Экстренные контакты и связь (SOS):**
   - Быстрый доступ к телефонам родственников, социального работника и экстренных служб.
   - Кнопка мгновенного вызова тревоги (**«ВЫЗОВ SOS»**) с отправкой оповещения и координат.
4. **Инклюзивность и доступность (Accessibility):**
   - Увеличенная типографика (базовый шрифт от `20px`) и крупные интерактивные элементы.
   - Переключение в **режим высокого контраста** (жёлтый текст на чёрном фоне) для пользователей с нарушением зрения.
   - Упрощённая линейная навигация без сложных вложенных меню.
   - Модуль **голосового управления** для навигации по разделам с помощью голосовых команд.

---

## Технологический стек

- **Платформа:** .NET / ASP.NET Core Blazor (Razor Components)
- **UI-компоненты:** Telerik UI for Blazor or Microsoft Visual Studio (`TelerikGrid`, `TelerikCard`, `TelerikButton`, `TelerikDialog`, `TelerikNotification`, `TelerikTextBox`)
- **Языки:** C#, HTML5, CSS3, JavaScript (Web Speech API для голосовых команд)
- **База данных и ORM:** Реляционная СУБД (SQLite / PostgreSQL / MS SQL) + Entity Framework Core
- **Проектирование:** Принципы ООП, модульная архитектура, UI/UX-прототипирование с учётом стандартов доступности (WCAG)

## Архитектура проекта

Приложение построено по модульному принципу:

```text

├── Models/                 # Сущности предметной области (MedicationReminder, DoctorAppointment, EmergencyContact)
```

## Установка и запуск

### Вариант 1. Запуск в Visual Studio / локально
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com<ваш-логин>/timurovets-blazor.git
   cd timurovets-blazor
   ```
2. Убедитесь, что установлен **.NET SDK** (версии 8.0 или выше) и настроена лицензия/пакет `Telerik.UI.for.Blazor`.
3. Восстановите зависимости и примените миграции базы данных:
   ```bash
   dotnet restore
   dotnet ef database update
   ```
4. Запустите приложение:
   ```bash
   dotnet run
   ```
5. Откройте в браузере адрес, указанный в консоли (обычно `https://localhost:5001`).

### Вариант 2. Быстрый предпросмотр UI в Telerik REPL
Код интерфейса из `Pages/Index.razor` можно запустить без локальной установки в онлайн-песочнице [Telerik REPL for Blazor](https://telerik.com "Telerik REPL for Blazor"), вставив содержимое компонента в файл `__Main.razor`.

## Тестирование и контроль качества

При разработке проведена проверка следующих сценариев:
- Корректность добавления, отображения и изменения статуса напоминаний о приёме лекарств.
- Переключение между стандартной и высококонтрастной темами оформления без потери читаемости элементов.
- Работа всплывающих уведомлений (`TelerikNotification`) при вызове SOS и отправке напоминаний близким.
- Адаптивность интерфейса при масштабировании экрана до 150–200%.
